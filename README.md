A beautifully designed, fully functional, and interactive **Music Player Widget** built using pure HTML, CSS, and Vanilla JavaScript. No external frameworks or libraries!

## ✨ Features

### 🎧 Core Functionality (JavaScript)
- **Dynamic Playback:** Reads audio file progress and duration in real-time.
- **Interactive Playlist:** Seamlessly scroll through the tracklist and select songs to play.
- **Track Controls:** Fully functional *Play, Pause, Previous*, and *Next* buttons.
- **Keyboard Accessibility:** Control playback using the `Spacebar` and navigate tracks using `Left/Right Arrows`.
- **Dynamic UI:** Album covers update instantly when the active track changes.

### 🎨 Styling & Animation (CSS)
- **Ambient Lighting Background:** The background dynamically blurs and adapts based on the current album cover.
- **Smooth Transitions:** Custom easing curves and hover states for all interactive elements.
- **Typography:** Styled cleanly using Google Fonts.
- **Pure CSS:** 100% vanilla CSS—zero dependencies.

## 💻 Getting Started

To run this project locally, simply clone the repository and open the `index.html` file in your preferred web browser.

```bash
# Clone this repository
git clone https://github.com/IqbalMind/Music-Player-Widget-using-html-css-and-js.git

# Navigate into the directory
cd Music-Player-Widget-using-html-css-and-js
```

Then, double click `index.html` or open it in your browser to experience the music player!
